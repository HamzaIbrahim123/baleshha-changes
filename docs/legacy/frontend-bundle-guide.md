# Baleshha source change bundle — 2026-11-15

This directory contains the complete changed/new source files for the initial Baleshha React implementation based on Figma designs.

**Source commit:** https://github.com/HamzaIbrahim123/baleshha/commit/54a229e1a9a11e3faaf33c5b558610a425b705de

**Apply:** Copy the files from this directory into the matching paths of the project root (preserve relative paths and executable permissions on .figma/make/*). Or download the repository's source ZIP.

**Run:** npm install && npm run dev

**Archive note:** This repository is the bundle; individual files are intentionally exposed for line-by-line review.

No server-side account system, real question database or cross-device persistence is included.
