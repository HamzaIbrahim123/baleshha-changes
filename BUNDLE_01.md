## Status and use

Run `npm install && npm run dev` at the repository root. This is a frontend **demo**, not cross-device accounts or a production question bank; it currently persists game state locally. Backend integration is a separate task (Bundle 03). Do not copy these files into the separate original `baleshha` repo without an explicit request.
